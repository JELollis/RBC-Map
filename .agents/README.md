# RBC-Map Agent Coordination

This directory holds the proposed multi-agent development operating procedure.

- [MULTI_AGENT_PLAN.md](MULTI_AGENT_PLAN.md): Roles, sequence, quality gates, pilot and automation criteria.
- [HANDOFF_PROTOCOL.md](HANDOFF_PROTOCOL.md): Standardized agent-to-agent records and findings.
- `handoffs/`: Intended location for future issue-specific handoff reports (create when needed).

Agent order: **Codex -> Claude Code -> Devin -> Greptile -> CI + maintainer approval**.

This documentation does not install or authorize any agent, configure credentials, enable CI, or permit automatic merges. The maintainer controls branch targets, scope, costs, permissions and release decisions.
